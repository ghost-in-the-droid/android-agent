# SOFT notes: whatsapp-messaging

Use these notes when re-mining this skill for a different WhatsApp build.

1. Launch `com.whatsapp`; wait for the chat list (`desc: Search`).
2. Tap search, type the contact name, tap the first row whose text equals the name.
3. Type into the composer (`id: entry`), tap `desc: Send`.
4. Success: the message text is visible with a single or double tick.
