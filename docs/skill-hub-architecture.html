Skill Hub: who runs what, where

Five places take part. Nothing runs on a Ghost server: GitHub hosts the repo and the CI, a CDN serves files, the author's and the user's machines drive phones over ADB. The one place a Ghost-operated service exists is the optional telemetry worker, and it only ever receives enums.
